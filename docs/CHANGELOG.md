## 🇺🇸 English

## [1.0.0] - 2026-03-23

### Features
- ✨ One-click creation of bookmarks for Zotero references
- 🔗 Add jump links to main text citations
- 🎯 Support single citation `[1]` and multiple citations `[1,2,3]`
- 🛡️ Special handling for the last reference jump issue
- ⚡ Batch processing for entire documents

### Technical Details
- Implemented using Word VBA macros
- Compatible with Word 2016/2019/2021/Microsoft 365
- Support Zotero 6.x and 7.x
